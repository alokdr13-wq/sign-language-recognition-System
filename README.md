# Sign Language Recognition System

A real-time American Sign Language (ASL) recognition project using Python, Convolutional Neural Networks (CNN), Keras, TensorFlow, and OpenCV.

## Technologies Used
- Python
- TensorFlow and Keras
- OpenCV
- NumPy
- Scikit-learn
- SQLite

## Project Features
- Hand gesture image capture
- Hand segmentation using histogram techniques
- Image augmentation
- CNN-based gesture classification
- Webcam-based sign recognition
- Text-to-speech support

## Project Workflow
1. Capture gesture images.
2. Prepare and label the dataset.
3. Train the CNN model.
4. Recognize gestures using a webcam.

## Project Status
The source code has been uploaded. The trained model and required dataset must be available before running the complete recognition application.
